# 哈工大三角洲校队网页 — 设计规格

日期：2026-10-06
状态：已实现，本地验证通过

## 1. 目标

给学校三角洲（Delta Force）校队做一个对外门面网页，同时承担**招新宣传**职能。

成功标准：一个同学 / 老师打开链接，30 秒内能明白「这是什么队伍、打得怎么样、有哪些人、怎么加入」。

## 2. 约束

| 约束 | 来源 | 影响 |
|---|---|---|
| 完全免费 | 用户明确要求 | 静态托管 + 无付费服务；不用 Google Fonts 等外部 CDN |
| 内容基本不做日常更新 | 用户确认 | 不做 CMS、不做后台 |
| 不做在线报名表单 | 用户确认 | 招新只留 QQ 群 / 微信联系方式 |
| 视觉风格 = 暗色电竞风 | 用户指定参考站（两次） | 深紫卡片 + 绿色强调 + 大图首屏 |
| 参考站结构 | `www.wanshitong.top/bxb/teamRoster`、`yl.yun123.shop` | 横向顶部导航 + 全屏首屏 + 数据条 + 可展开卡片 |
| 配色沿用已定方案 | 用户「风格不用变化」 | 只换结构，改版时不重做配色 |
| 素材由用户陆续提供 | 已收到队徽 + QQ 群二维码 | 其余图片先用占位图交付 |

## 3. 技术方案

**纯静态四件套，零依赖零构建。**

- `index.html` + `css/style.css` + `js/data.js` + `js/main.js`
- 无框架、无构建步骤、无 `node_modules`
- 双击 `index.html` 即可本地预览
- 托管：GitHub Pages

**明确排除：**

- Astro / Hugo 等静态生成器 —— 对「一次性宣传页且几乎不改」是过度设计，还引入 Node 构建步骤
- Tailwind CDN / Google Fonts —— 依赖外网，国内加载不稳定，断网即失效
- 任何前端框架（Vue / React）—— 页面交互量用原生 JS 足够，引入框架反而增加维护负担

## 4. 页面结构（单页滚动）

| # | 位置 | 内容 | 交互 |
|---|---|---|---|
| 0 | 顶部导航 | 队徽 + 队名 + 6 个锚点（首页/队伍简介/战绩荣誉/队员名单/比赛图集/加入我们）+ 「加入我们↗」按钮 | 滚动吸附、当前板块高亮、窄屏折叠成汉堡菜单 |
| 1 | 首屏 | 小字标签 + 两行大标题（HIT / DELTA TEAM）+ 主标语 + 简介 + [申请加入][查看战绩] | 全屏大图、底部数据条、「向下探索」提示 |
| 2 | 队伍简介 | 三段队伍介绍 | 滚动淡入 |
| 3 | 战绩荣誉 | 卡片列表：月份/年份方块 + 赛事名 + 说明 + 名次胶囊 | 悬停上浮 |
| 4 | 队员名单 | 卡片列表：头像 + 昵称 + 游戏ID + 「展开资料」按钮 | 手风琴展开，显示位置/段位/入队时间/一句话 |
| 5 | 比赛图集 | 图片网格 | 点击灯箱放大、← → 切换、Esc 关闭 |
| 6 | 加入我们 | 招募要求 + QQ 群二维码卡片 + 微信号 + 常见问题 | 一键复制群号 |
| 7 | 页脚 | 版权 + 最后更新日期 | 右下角浮动回到顶部按钮 |

**为什么首屏数据条而不是「关于」里的数据格：** 参考站把队伍数字放在首屏做钩子，视线第一落点就能看到规模；放进「关于」板块会被折叠到第二屏之后。

## 6. 数据结构

`js/data.js` 定义四个全局数组：

```js
var STATS        = [{ value, label }];                                  // 首屏数据条
var ACHIEVEMENTS = [{ date:'YYYY-MM', title, rank, desc }];             // 战绩，新→旧
var MEMBERS      = [{ name, gameId, role, rank, joined, quote, avatar }];
var GALLERY      = [{ src, caption }];
var RECRUIT      = { intro: [string], groups: [{ title, note, blocks: [{ label, items: [{ name, reqs:[string] }] }] }] };
```

`RECRUIT` 是招新考核标准，来源《HIT三角洲行动校队全面战场考核标准规范》，目前含 3 条总则、4 个大类（载具 / 步战 / 综合 / 免考）、12 张岗位卡片、42 条要求。

约定：

- `date` 必须是 `YYYY-MM`，页面自动拆成年 / 月显示
- `avatar` 为空字符串时回落到 `images/members/default.svg`
- 单条文字（队名、标语、简介、招新要求、联系方式、FAQ、版权）**不放进 data.js**，直接写在 `index.html` 并用 `↓↓ 改这里` 注释标记 —— 单次出现的内容写在 HTML 里，无 JS 也能看到主要内容

## 10. 部署（GitHub Pages，全免费）

1. 注册 / 登录 GitHub
2. 新建 **Public** 仓库（免费版 Pages 只支持公开仓库）
3. `git init` → `commit` → `push`
4. Settings → Pages → Source 选 `Deploy from a branch` → `main` + `/ (root)` → Save
5. 访问 `https://<用户名>.github.io/<仓库名>/`
